# US Social Determinants of Health Maps

This directory contains maps for the US Social Determinants of Health dataset.

## Map Organization

- **by_year/**: Maps organized by year, with filenames like `YEAR_VARIABLE.png`
- **by_variable/**: Maps organized by variable, with filenames like `VARIABLE_YEAR.png`
- **combined/**: Combined maps with multiple variables for each year (`combined_YEAR.png`) and time series maps for each variable (`timeseries_VARIABLE.png`)

## Map Coverage

- **Time Period**: 1970 to 2022
- **Variables**: 284 variables mapped across various domains
- **Geography**: Maps show the entire United States, including Alaska, Hawaii, and territories
