# Map Outputs Directory

## Overview

This directory contains county-level and state-level maps generated by the Social Determinants of Health pipeline. These maps visualize various health, social, economic, and environmental indicators across the United States.

## Directory Structure

The maps are organized into three main subdirectories:

```
output/maps/
├── by_variable/        - Maps organized by variable type
├── by_year/            - Maps organized by year
└── combined/           - Multi-variable composite maps
```

### by_variable Directory

Maps in `by_variable/` show the geographic distribution of a single indicator across all available years. This allows for tracking trends in a specific indicator over time.

Example: `output/maps/by_variable/median_household_income/`

### by_year Directory

Maps in `by_year/` show multiple indicators for a specific year. This allows for comparing different indicators for the same time period.

Example: `output/maps/by_year/2020/`

### combined Directory

Maps in `combined/` show composite indicators created from multiple variables, such as:
- Overall social vulnerability index
- Economic opportunity index
- Environmental health burden

## Map File Naming

Map files follow this naming convention:
- Individual maps: `<variable_name>_<year>_<geography_level>.png`
- Time series maps: `<variable_name>_<start_year>_<end_year>_<geography_level>.png`
- Animated maps: `<variable_name>_<start_year>_<end_year>_<geography_level>.gif`

## Map Generation

Maps are generated using:
- `generate_county_maps.r` - Creates county-level choropleth maps
- `generate_conus_maps.r` - Creates continental US maps with state boundaries

To generate maps:
```r
# Generate maps for all variables
Rscript R/generate_county_maps.r

# Generate maps for specific variables
Rscript R/generate_county_maps.r --variables="median_household_income,life_expectancy"

# Generate maps for a specific year range
Rscript R/generate_county_maps.r --start-year=2015 --end-year=2022
```

## Map Features

All maps include:
- Color-coded choropleth based on variable values
- County or state boundaries
- Legend showing value ranges
- Title with variable name and year
- Data source attribution
- Timestamp of generation

## Visualization Options

Maps can be customized by modifying parameters in `config.yaml`:

```yaml
mapping:
  color_scheme: "viridis"  # Options: viridis, magma, plasma, inferno, RdYlBu, etc.
  resolution: "high"      # Options: high, medium, low
  include_alaska_hawaii: true
  show_state_boundaries: true
  show_county_names: false
  map_format: "png"       # Options: png, pdf, svg, jpg
```
